**PocketPro** is a modern, feature-packed personal finance web application built for seamless tracking of daily expenses, incomes, savings goals, upcoming bill reminders, loans & EMIs, and group expense splits (Splitwise style).

---

## 🌟 Top Viral Features

- 📲 **Bank SMS Auto-Parser**: Extract transactions automatically from bank SMS.
- 📷 **Live Receipt Scanner (OCR)**: Scan physical bill receipts to auto-log expenses.
- 🎙️ **Voice AI Expense Recorder**: Speak natural Hindi/English commands (e.g. *"Spent 250 on food"*).
- 💬 **WhatsApp Statement Sharing**: Share 1-tap financial summaries & Splitwise dues directly to WhatsApp contacts.
- 📲 **Certified PWA Offline Support**: Install on Android & iOS as a standalone native app.
- 👥 **Split Udhar (Splitwise)**: Track shared group expenses with friends and settle up balances.
- 🏦 **Loans & EMI Manager**: Track borrowed loans, given loans (Udhar), and Kist reminders.
- 🔒 **Multi-User Isolated Storage**: Log in with any username slug for 100% clean account data isolation in `localStorage`.
- 🌍 **7-Language App Translation**: Supports English 🇬🇧, Hindi 🇮🇳, Marathi 🇮🇳, Punjabi 🇮🇳, Gujarati 🇮🇳, Tamil 🇮🇳, and Bengali 🇮🇳.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js `v18+` or `v24+` installed.

### Installation & Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/AshGaming8813/Finflowpro.git

# 2. Navigate into the directory
cd Finflowpro

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The app will start at `http://localhost:5173`.

---

## 🛠️ Build for Production

```bash
npm run build
```

The compiled output will be generated inside the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
